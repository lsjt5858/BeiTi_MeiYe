先别急着买工具。问清学校提供的是课堂借用、每人赠送，还是需要自购，再按课程清单采购。新手工具没有统一总价：品牌、数量、容量差一档，支出就差一截，所以这里不给一个笼统金额。

## “含工具”还要问能否带走

| 课程约定 | 需要继续确认 |
| --- | --- |
| 课堂提供工具 | 是否共享、是否足够，课后练习怎么办 |
| 每人一套工具 | 具体清单、品牌型号和数量，结业是否归你 |
| 学员自备 | 哪些必需，能否自行采购，有无指定型号 |
| 校内购买 | 是否必须购买，总价多少，是否影响上课 |

“学费全包”也要列明包含项，不能默认学校提供的每件工具都可以带走。报价中没有写清的项目，先问，不要交费后再猜。

## 基础先够用，其他工具跟着课程添

可以从课程需要的修型用品、基础色胶、配套灯具、笔刷和练习材料开始。具体品类由所学项目决定，不照着“大而全套装”盲买。

消毒、清洁和安全用品不应被当成可有可无的进阶配置。涉及指缘处理、打磨或其他精细操作的工具，要在正确指导下使用；不是买到了就可以直接上手。

延长、特殊设计等材料，等确定课程需要再添。不要为了用满一张色板囤货，也不要仅看套装件数，忽略用品是否真正能用。

## 工具多少钱，按实际清单比

核对同一品牌型号、容量、数量和适用性，再看价格。套装和逐件买有时价差明显，但哪边便宜要看具体清单，不能凭经验断言。

同时问耗材多久需要补、谁承担练习损耗。开课时一次买工具的钱和持续练习花的钱，分开记录。

## 交费前把这些问题问完

学费含哪些工具与材料？结业后哪些归自己？是否允许自备，是否必须在校内购产品？课后和复训的耗材怎么算？

答案最好出现在费用明细或协议里。暂时说不清就先不买，尤其不要因为报名优惠被要求连带购入一整套产品。
