杭州没有一份可查的“包教包会”学校名单，谁都可以在招生页上这么写。判断这类承诺，先问怎么考核、没达到要求怎么办，再问复训的期限、内容和费用——能继续学，不等于一定能就业、接单或回本。

![复习练习主题示意图，非贝缇真实复训或学员成果](/images/gallery/nails/02.jpg)

## “会”要对应具体任务

只说上完课程算学会，和要求独立完成一项服务，是不同标准。问清考核内容、谁评定、什么情况需要补学，以及补学之后如何再确认。

“学会为止”具体保到什么程度，要看考核和期限怎么写；结业证也只证明你完成了课程，不代表能处理所有客人的需求。

## 免费复训，哪些内容真的免费

| 需要核对 | 为什么要问 |
| --- | --- |
| 期限 | 从报名、开课还是结业开始算 |
| 内容 | 原课程重学、单项补学，还是可以参加新课程 |
| 预约与次数 | 是否需要等班期，有无名额或次数限制 |
| 材料与工具 | 学费不收，耗材或工具是否另收 |
| 调整或停班 | 课程变化后，原约定如何继续提供 |

“免费”最好落实到具体项目。对方能解释清楚还不够，招生说明和协议上的写法要能对上。

## 复训不是第一次教学的替代

报名时仍要看正常课程怎样指导、实操如何安排。不能因为“以后还能回来”就忽略当期有没有足够的上手机会。

能试听的话，观察老师是否针对操作问题给反馈。是否免费试听也要问，不宜默认杭州所有机构都提供。

## 如果你能投入的时间不稳定

先查复训与自己的日程能否匹配。只能等很久的下一期，或规定时段你无法到课，对你就未必有用。

复训解决的是继续学习的安排，接单还需要实际能力和客源。不要因为担心学不会，就把更大的收入预期放进报名决定。

## 贝缇的复训，先把场地费算进去

贝缇复训收取 **500 元场地费**，不能理解成完全免费。2025 版美甲课件写了“两年内免费复训（复训收500场地费）”；其中的期限、适用课程、次数和预约方式，仍要和自己的课程约定核对，不能套用到所有班型。

| 核对项 | 贝缇目前能说明的内容 |
| --- | --- |
| 复训费用 | 500 元场地费 |
| 期限与范围 | 以适用课程的书面约定为准 |
| 到课安排 | 复训前先与校区核对预约和开课安排 |
